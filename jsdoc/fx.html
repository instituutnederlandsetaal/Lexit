Namespace: fx

fx

This set of functions is an extension to the basic set of functions contained in the fn namespace.
The functions of the fx namespace make use of the 'new' Datatables API, that offers the possibility to point at rows and cells by using API object instances of rows and cells, instead of using TD/TR nodes (which is taken care of in the fn namespace).
