Namespace: lists

lists

The lists namespace contains functions to build tables as part of a form. A list is filled with the content of a table matching some values.

Build the id of a list container (DIV), given the form id and the list label. The id to be built is like 'FORM_ID___LISTLABEL' (where FORM_ID is the name of the table underlying the form, to which the string '_form' is appended).
